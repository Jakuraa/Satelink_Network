# Satelink AI Assistance — product context (Release State A)

**What it is:** a universal AI Assistance and Agent Commerce platform (Jakuraa Commercial Private Limited). Humans,
developers, AI agents and machines describe an outcome; Satelink routes a model (OpenRouter), discovers capabilities
from ONE registry, plans, quotes, gets approval, executes, verifies and returns a receipt.

**What it is not:** a trading platform, MCP marketplace, chatbot or API aggregator. Trading AI is one workflow.

**Business model:** pay-per-use; disclosed Satelink fee on completed workflows; no mandatory subscription.
Release A charges nothing. Fees in `config/pricing.preview.json` are **PROPOSED — NOT APPROVED**.

**Actors:** human · developer · agent · machine (`actor_type`).

**Primary journey:** signup → onboarding → assistant → model routing → capability discovery → plan → quote →
approval → simulated execution → verification → receipt → usage.

**Copy rules:** say "Preview — simulated, no charges"; receipts "SIMULATED — NO MONEY MOVED"; trading
"SIMULATED_PAPER_EXECUTION: NOT_ACTUAL_RETURNS"; mock suppliers "<name> (MOCK)"; no third-party logos; no
partnership, price, performance or revenue claim that is not true today; not investment advice.

**Money truth:** revenue = `origin='external' AND environment='live'` only. Preview revenue is $0.00 by construction.
Credits may only pay Satelink's own fee; suppliers are paid by the user directly at the supplier's checkout.
