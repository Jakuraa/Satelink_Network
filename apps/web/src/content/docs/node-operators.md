> **The node operator program is paused. Operator payouts are not active.**

The Satelink RPC gateway once invited independent operators to register nodes
and serve routed traffic. That program is paused: no new operators are being
onboarded, nothing accrues to operators, and no operator is owed or promised
any payment.

If the program resumes, the [Node Operator Terms](/network/operator-terms) will
be updated first and this page will say so.

Questions: use the [contact page](/contact).
